# Таймшит для QA — установка и настройка

Локальная страница таймшита (вкладка `/timesheet`) для списания времени в Yandex
Tracker: таблица недели с предложениями по задачам и кнопкой «Списать». Роль —
`qa` (тестирование считается основной работой). Работает на вашем Mac, данные
никуда не отправляются: GitLab и Трекер читаются по вашим же токенам.

## Что подготовить до установки

1. **GitLab PAT** (scope `read_api`):
   gitlab.lmru.tech → аватар → *Edit profile* → *Access tokens* → *Add new token*
   → имя `lpdev-qa`, scope **read_api**, срок — на ваш выбор. Скопируйте токен
   (`glpat-…`) сразу: потом он не показывается.
2. **OAuth-токен Yandex Tracker** (`y0_…`): с правами `tracker:read`, а если
   планируете списывать время кнопкой — `tracker:write`. Получение:
   - создайте приложение на https://oauth.yandex.ru/client/new/api — получите
     **ClientId** (при создании отметьте доступ к Яндекс Трекеру с нужными
     правами: `tracker:read`, для кнопки «Списать» — `tracker:write`);
   - откройте `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientId>`
     и разрешите доступ — токен `y0_…` появится в адресной строке страницы.
   - отозвать выданный доступ приложению можно в любой момент:
     https://id.yandex.ru/personal/data-access
3. **org_id** — ID организации в Трекере; по умолчанию уже подставлен `7867633`
   (наша организация).
4. **Ключи очередей** вашей команды (например `SUPERAPP`), через запятую.

## Установка

1. Распакуйте архив (`lpdev-qa-…zip`) в удобное место, например в
   `~/Applications/lpdev-qa`. Внутри: папка `lpdev-qa`, файл
   `Lemanapro Timesheet.command`, этот `INSTALL.md`.
2. Снимите карантин macOS (файлы из чата блокируются Gatekeeper) и проверьте
   хеш, если он приложен к сообщению со сборкой:
   ```bash
   xattr -dr com.apple.quarantine ~/Applications/lpdev-qa
   shasum -a 256 <путь к zip>   # сверьте с хешем из поста
   ```
3. Запустите **`Lemanapro Timesheet.command`** (двойной клик) или в Terminal:
   `./lpdev-qa/lpdev-qa`

## Первый запуск — мастер настройки

Бинарь задаст несколько вопросов (Enter — значение по умолчанию):

| Вопрос | Что вводить |
|---|---|
| GitLab URL | `https://gitlab.lmru.tech` (Enter) |
| GitLab PAT | вставьте `glpat-…` (ввод скрыт); проверится запросом в GitLab |
| Tracker org_id | Enter (7867633) или ID другой организации |
| Очереди | ключи через запятую, например `SUPERAPP` |
| Списывать время? | `y` — с кнопкой «Списать» (нужен `tracker:write`), `n` — только просмотр |
| OAuth-токен Трекера | вставьте `y0_…` (ввод скрыт); проверится запросом в Трекер |
| Порт | Enter (8124) |

Токены сохраняются в **Keychain** (service `lpdev-qa`), в конфиг они не
пишутся. Если macOS спросит «…хочет получить доступ к связке ключей» — нажмите
**«Всегда разрешать»**. Конфиг лежит в `~/.config/lpdev-qa/config.yaml`,
данные (база, логи) — в `~/lemanapro-timesheet/`.

После настройки сразу откроется браузер с `http://127.0.0.1:8124/timesheet`.

## Повторные запуски

- Просто запустите `.command` снова: старый экземпляр (если остался) будет
  остановлен, откроется свежая вкладка браузера.
- **Ctrl+C** в окне Terminal останавливает сервис и закрывает вкладку
  (браузер спросит разрешение на автоматизацию — можно разрешить; если запретить,
  вкладку закройте вручную).
- Порт можно поменять: `./lpdev-qa/lpdev-qa --port 9000` (на этот раз), либо
  перезапустить мастер: `./lpdev-qa/lpdev-qa --setup`.

## Обновление и сброс

- **Обновление**: сначала остановите сервис (`Ctrl+C` в его окне), удалите
  старую папку `lpdev-qa` (`rm -rf lpdev-qa`), распакуйте новый архив и
  повторите шаг 2 (`xattr`). Не распаковывайте поверх — в `lpdev-qa/_internal`
  останутся файлы прошлой версии. Настройки и данные (в `~/.config/lpdev-qa`
  и `~/lemanapro-timesheet`) сохраняются.
- **Сброс настроек**: `rm -rf ~/.config/lpdev-qa` и запустите заново с `--setup`.
- **Полный сброс**: то же + `rm -rf ~/lemanapro-timesheet`.

## Если что-то не работает

- «Порт занят» — закройте старый экземпляр (Ctrl+C в его окне) и запустите снова.
- «GitLab отклонил PAT» — проверьте scope `read_api` и срок действия токена
  (GitLab → Access Tokens), затем `--setup`.
- «Трекер отклонил токен» — проверьте org_id и права токена (`tracker:read`,
  для списания — `tracker:write`), затем `--setup`.
- Логи: `~/lemanapro-timesheet/logs/app.log`.
