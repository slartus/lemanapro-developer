# mr-watch — итоговый отчёт

**Дата:** 2026-11-07 · **Статус:** готов, E2E пройден на реальном GitLab
**Репозиторий:** `~/projects/mr-watch` · **UI:** http://127.0.0.1:8123

## Что сделано

Локальный сервис автокода-ревью для self-hosted GitLab: поллит GitLab,
находит MR, где пользователь упомянут / назначен ревьювером / автор,
автоматически ревьюит через `opencode run` (read-only агент), результат —
в SQLite + веб-UI. Ничего не пишет в GitLab.

| Компонент | Файл | Суть |
|---|---|---|
| Конфиг | `src/mrwatch/config.py` | YAML: GitLab URL/PAT-команда, проекты↔агенты, ретраи, пути; pydantic-валидация |
| БД | `src/mrwatch/db.py` | SQLite WAL: project/mr/review/poll_state; claim через BEGIN IMMEDIATE; бэкап |
| API-клиент | `src/mrwatch/gitlab_client.py` | todos + keyset-пагинация, ретраи 429/5xx, mark_as_done |
| Поллер | `src/mrwatch/poller.py` | триггеры: todo (mentioned/reviewer/автор) + sweep по updated_after (новые/push) |
| Git | `src/mrwatch/git_ops.py` | shallow-клон MR-head, санитизация (.opencode, opencode.json*), diff base…head |
| Runner | `src/mrwatch/opencode_runner.py` | `opencode run --agent --format json --pure`, таймаут SIGTERM→SIGKILL, маскирование glpat/Bearer |
| Воркеры | `src/mrwatch/worker.py` | N параллельных, ретраи клон-фазы (до 3), opencode-fail без авторетрая, гард диска <5ГБ |
| Сервер | `src/mrwatch/main.py` | lifespan, /healthz, Host-check (127.0.0.1/localhost), nightly backup |
| UI | `src/mrwatch/web/` | список MR/ревью, страница ревью, Retry (защита CSRF через X-Requested-With) |
| Агент | `~/.config/opencode/agent/mr-watch-reviewer.md` | read-only (deny write/edit/bash/webfetch, deny .env*/secrets/*.key), anti prompt-injection, вердикт APPROVE/…/REQUEST_CHANGES |
| Деплой | `deploy/` | launchd plist (ru.slinkin.mr-watch) + install.sh + README |

## Дефекты, найденные и исправленные

1. **[MAJOR]** ~ в opencode.bin не разворачивался → падение subprocess (E2E).
2. **[MAJOR]** бесконечный цикл re-review (pending todo + авто-ретрай done) → поллер теперь create_review без ретрая; retry остался только в UI.
3. mark_as_done вместо mark_as_read (404), PLAN поправлен.
4. Статус 'reviewing' не выставлялся → db.mark_reviewing.
5. OpencodeError → структурный error вместо 'internal worker error'.
6. (чанки 1–4, кратко) pagination-кап, стартовый курсор now−backfill, Bearer-маскирование, уникальный askpass, user_version-миграции и др. — см. CHANGELOG.

## Безопасность (ключевые решения)

- PAT только в macOS Keychain; в opencode не попадает (GIT_ASKPASS, минимальный env, маскирование в логах/результатах).
- Клон санитизируется (.opencode/opencode.json* удаляются) + `--pure`; агент read-only с deny-паттернами.
- Веб только 127.0.0.1 + Host-check; ревью рендерится как текст (autoescape).
- Секреты не коммитятся (`.gitignore`: config.yaml, data/, workspaces/, logs/, .venv/).

## Ограничения / что осознанно не сделано

- Todo в GitLab остаются pending: для mark_as_done нужен write-scope; дедап (mr_id, head_sha, trigger) защищает от повторных ревью.
- launchd-деплой подготовлен, но не активирован (install.sh запускать пользователю); сейчас сервис работает из /tmp/opencode/mrwatch-venv вручную.
- Ревью-субагент трижды возвращал пустой ответ от Task-инструмента — ревью делал оркестратор (зафиксировано в CHANGELOG).
- Мульти-проектность в конфиге есть, E2E прогнан на одном проекте.

## Как эксплуатировать

```bash
cd ~/projects/mr-watch
./deploy/install.sh          # venv + config.yaml + plist + launchctl load
# вручную:
MRWATCH_CONFIG=$PWD/config.yaml .venv/bin/uvicorn mrwatch.main:get_app --factory --host 127.0.0.1 --port 8123
```

Логи: `logs/app.log` (ротация 5×5МБ) + `~/Library/Logs/mr-watch/`.
Повтор ревью: кнопка Re-review в UI или `retry_review()`; принудительно новое: `request_review()`.
