# Готовая сборка таймшита для QA — 2026-11-10

## Задача

«для qa давай сделаем сборку и что им надо настраивать». Утверждённый план:
macOS arm64, готовая сборка (без git clone), PyInstaller-бинарь с мастером
настройки, повторный запуск гасит старый инстанс и открывает браузер,
Ctrl+C останавливает сервис и закрывает вкладку.

## Что сделано

- `src/lpdev/qa_setup.py` — мастер: GitLab URL (дефолт `gitlab.lmru.tech`),
  PAT `read_api` → verify `GET /user` → Keychain `lpdev-qa/gitlab`; org_id,
  очереди (дефолт `SUPERAPP`), «Списывать?» (`y/n`), OAuth-токен Трекера →
  verify `/myself` → Keychain; порт → sidecar `~/.config/lpdev-qa/port`
  (в YAML нельзя — pydantic `extra=forbid`). Конфиг 0600, `role: qa`,
  токены в конфиг не пишутся (только `*_command` на `/usr/bin/security`).
- `src/lpdev/qa_main.py` (entry `lpdev-qa`) — конфиг из `LPDEV_CONFIG` или
  `~/.config/lpdev-qa/config.yaml`; нет конфига / `--setup` → мастер; pidfile
  `lpdev-qa.pid` рядом с БД содержит pid + `ps -o lstart=` — kill прошлого
  инстанса только при точном совпадении (PID-reuse после ребута безопасен);
  SIGTERM → 10 с → SIGKILL; вкладка браузера открывается через 1 с, закрытие
  — osascript только для уже запущенных Chrome/Safari (не поднимает браузер),
  atexit только если браузер открывали; `ConfigError` → подсказка `--setup`,
  Ctrl+C до uvicorn → exit 130 без traceback.
- `deploy/qa/build.sh` — PyInstaller one-dir (`--add-data` шаблоны/статика/
  календарь, hidden-imports uvicorn/anyio), ad-hoc codesign, только из чистого
  дерева, zip + `Lemanapro Timesheet.command` + `INSTALL.md`, печатает commit
  и sha256; `pyinstaller==6.22.3` зафиксирован.
- Тесты: `tests/test_qa_setup.py` (19) + `tests/test_qa_main.py` (17) — 36;
  полный сьют **1330 passed**, ruff чист.
- README (секция про готовую сборку), `deploy/qa/INSTALL.md`, CHANGELOG.
